# Everquint assignment

two problems: a frontend build and a dynamic programming problem.

- **water tank** (`/water-tank`): vanilla js + html/css, renders the trapped water as an svg
- **max profit** (`max-profit.js`): node script computing the optimal mix of buildings for a given time


## running it

**water tank.** open `water-tank/index.html` in a browser. enter an array such as `0,4,0,0,0,6,0,6,4,0` and click visualize. blocks render in yellow, trapped water in blue.

**max profit.** run `node max-profit/max-profit.js`. test cases are at the bottom of the file.
